# Assignment 2 — Python Fundamentals

## Overview

This assignment covers basic Python concepts including conditional statements, dictionaries, user input, and file handling.

## Tasks

### 1. Grade Checker

Takes a student's score as input and prints the appropriate grade from **A to F** using `if-elif-else`.

**Concepts:** `input()`, `if`, `elif`, `else`, comparison operators.


### 2. Student Grades

Uses a dictionary to store student names and grades. The program allows the user to:

* Add a new student and grade
* Update an existing student's grade
* Print all student grades

**Concepts:** Dictionary, key-value pairs, `if-elif-else`, dictionary operations.

### 3. Write to a File

Creates `example.txt` and writes content into the file.

**Concepts:** `open()`, write mode (`"w"`), `write()`, `close()`.

### 4. Read from a File

Opens `example.txt` in read mode, reads its contents, and displays them.

**Concepts:** `open()`, read mode (`"r"`), `read()`, `print()`, `close()`.
